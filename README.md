# 🔥 Попіл Ашторна — top-down dark fantasy RPG

Браузерна action-RPG на чистому JS/Canvas (без залежностей). Відкрий `index.html` у браузері — і грай.
(або `python3 -m http.server` у корені та `http://localhost:8000`)

## Керування
| Дія | Клавіша |
|---|---|
| Рух | WASD |
| Атака | ЛКМ (утримуй) |
| Здібність класу | ПКМ / Q |
| Ухилення (i-frames) | Пробіл |
| Зілля | F |
| Взаємодія (NPC, вогнище, сувої, портал) | E |
| Пауза / звук / повний екран | Esc / M / G |

## Класи
| Клас | Стиль | Здібність |
|---|---|---|
| ⚔️ Лицар Попелу | ближній бій, дуга меча, багато HP | Удар Щита — хвиля, стан, відкидання |
| 🔥 Чорнокнижник Жару | вогняні кулі з вибухом і підпалом | Пекельна Нова — кільце вогню |
| 🏹 Тіньовий Стрілець | найшвидший, пронизливі стріли | Злива Стріл — віяло з 7 стріл |
| 💀 Могильний Жрець | самонавідні душі | Повстання Мерців — 3 кістяні слуги |

## Сюжет
Король **Мальгорат** злякався смерті й уклав угоду з Безоддю — ціною стала **Корона Попелу**. Прийшла Скверна. Ти — Пробуджений, у чиїх кістках ще тліє Жар.
1. **Прокляті Землі** — знайди Вартового Цвинтаря, відкрий портал.
2. **Катакомби Забутих Королів** — королева Ейра розкаже правду: Корона не дає безсмертя, вона дає *заміну*.
3. **Трон Попелу** — бій із Мальгоратом (2 фази) і вибір: **розбити Корону** або **вдягнути її** (2 кінцівки).

## Що вже є
- Процедурні рівні (кімнати + коридори), туман війни/мінікарта, динамічне освітлення (смолоскипи, вогнище, чари)
- 4 класи, 4 типи ворогів + еліти + бос із патернами (удар, снаряди, виклик, ривок)
- Пошук шляху ворогів (BFS flow-field), ухилення з i-frames, крити, підпал, оглушення
- Досвід, рівні, вибір із 3 перків на рівень (10 перків, стакаються)
- Діалоги, NPC, сувої лору, вогнища-чекпоінти, зілля
- Піксель-арт 24×24+: персонажі малюються кодом по позі (`js/rig.js`) з автоматичним контуром і затінення, тайли — `js/sprites.js` (без зовнішніх файлів)
- Анімації: idle (4 кадри), ходьба (6), атака (4), каст (3), удар, кувирок героя; вид спереду/ззаду; пил від кроків; hit-stop
- Смерті: скелет розсипається на кістки, гуль тане, культист розсипається в пил, голем падає, бос вибухає; герой падає й гасне, піднімаються іскри
- Процедурна музика (`js/music.js`): окремі теми для меню, кожного рівня, боса й кінцівок; барабани вмикаються в бою
- Звукові ефекти синтезуються WebAudio
- Повноекранний режим (кнопка або G), HUD масштабується під розмір екрана

## Ідеї для розвитку
**Геймплей**
- Ще класи: Паладин-Інквізитор, Відьма (прокляття/DoT), Берсерк (rage), Асасин (stealth/backstab)
- Дерево талантів на клас + другий вибір при 5/10 рівнях (підкласи)
- Лут: зброя/броня з афіксами (рідкість: сіре → золоте), крафт біля вогнища, рунні слова
- Система «Скверни»: чим довше без вогнища — тим сильніші вороги й краща нагорода (ризик/нагорода)
- Парирування/блок, витривалість, важкі/легкі атаки для Лицаря
- Пастки, секретні кімнати, дзеркальні мімікри-скрині, руйнівне оточення

**Світ і сюжет**
- Хаб «Останній Вогонь» — торговець, коваль, чаклунка; сюжетні квести
- Нові біоми: Гнилі Болота, Собор Плачучих, Крижана Вежа, Вулкан Безодні
- Побічні боси-«Вісники» з унікальними механіками; моральні вибори (врятувати/пожертвувати NPC)

**Технічне**

- Gamepad, мобільне керування, кооп на двох
